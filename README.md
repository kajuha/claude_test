# 💀 DOOM - Web Edition

브라우저에서 바로 실행되는 Doom 스타일의 레이쾐스팅 1인칭 슈팅 게임입니다.  
외부 라이브러리 없이 순수 HTML5 Canvas + JavaScript로 구현되었습니다.

---

## 🎮 플레이 방법

### uv로 바로 실행 (권장)

[uv](https://docs.astral.sh/uv/)가 설치되어 있으면 한 줄로 실행됩니다.

```bash
uv run serve.py          # 기본 포트 8080, 브라우저 자동 오픈
uv run serve.py 3000     # 포트 직접 지정
uv run serve.py --verbose  # 요청 로그 출력
```

> `uv`가 없다면 `curl -LsSf https://astral.sh/uv/install.sh | sh` 로 설치하세요.

### Python 기본 서버로 실행

```bash
python3 -m http.server 8080
# → http://localhost:8080 접속
```

### 파일을 직접 열기

`index.html`을 브라우저로 드래그하거나 더블클릭해도 실행됩니다.  
(Pointer Lock은 `file://` 프로토콜에서 일부 브라우저에서 제한될 수 있습니다.)

### 조작키

| 키 | 동작 |
|------|------|
| `W` / `↑` | 앞으로 이동 |
| `S` / `↓` | 뒤로 이동 |
| `A` / `←` | 왼쪽 회전 |
| `D` / `→` | 오른쪽 회전 |
| `Q` | 왼쪽 회전 (보조) |
| `E` | 오른쪽 회전 (보조) |
| `Space` | 발사 |
| `F` | 앞의 문 열기/닫기 |
| **마우스 클릭** | 포인터 잠금 후 발사 |
| **마우스 좌우** | 시점 회전 (포인터 잠금 상태) |

> **마우스 조작**: 캔버스를 클릭하면 포인터가 잠기고 마우스로 자유롭게 시점을 돌릴 수 있습니다. `Esc`를 누르면 잠금이 해제됩니다.

## 🗺️ 맵 구성

20×20 타일 맵으로 구성되며, 였 3개의 구역과 6개의 문(타입 6)이 배치되어 있습니다.

```
벽 타입:
  1 = 외벽 (갈색)
  2 = 내벽 A (파랑)
  3 = 내벽 B (붉은)
  4 = 내벽 C (초록)
  5 = 내벽 D (황토)
  6 = 문 (금색, F키로 개폐)
```

## 👾 적 (Enemy)

| 속성 | 값 |
|------|-----|
| 옵 수 | 8명 |
| 체력 | 60–100 |
| 감지 거리 | 8타일 이내 접근 시 경계 상태 |
| 공격 거리 | 6타일 이내에서 발사 |
| 발사 간격 | 약 2–3초 (랜덤) |
| 이동 | 플레이어를 향해 추적 |

적이 경계 상태가 되면 미니맵에서 주황색으로 표시됩니다.

## 🎁 아이템

| 아이템 | 색상 | 효과 |
|------|------|------|
| ❤️ 체력 (Health) | 빨강 | 체력 회복 (+25 또는 +50) |
| 🔫 탄약 (Ammo) | 노랑 | 탄약 보충 (+20 또는 +30) |
| 🛡️ 방어구 (Armor) | 하늘색 | 방어력 부여 (+50) |

가까이 다가가면 자동으로 횟득됩니다.

## 🖥️ HUD (화면 정보)

| 항목 | 설명 |
|------|------|
| HEALTH | 현재 체력 (0–100%) |
| ARMOR | 현재 방어력 (0–100%) |
| 😐 얼굴 | 체력 상태 표정 (75/50/25% 기준 변화) |
| AMMO | 남은 탄약 수 |
| KILLS | 처치한 적 수 |

좌상단 미니맵에서 현재 위치(초록 점), 적(빨강/주황 사각형), 아이템(색상 점)을 확인할 수 있습니다.

## ⚙️ 기술 사양

| 항목 | 내용 |
|------|------|
| 렌더링 방식 | 레이쾐스팅 (Raycasting) |
| 해상도 | 800×480 |
| 시야각 (FOV) | 60° (π/3 rad) |
| 레이 수 | 800개 (화면 가로 픽셀당 1개) |
| 스프라이트 정렬 | Z-버퍼 기반 깊이 정렬 |
| 물고기눈 보정 | `cos(rayAngle - playerAngle)` 보정 적용 |
| 프레임 타이밍 | `requestAnimationFrame` + dt 기반 독립 갱신 |
